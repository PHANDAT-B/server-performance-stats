# Server Performance Stats Script

This project is a script Bash to check the performance of Linux system (CPU, RAM, process)
## Project Reference
This project was built following the requirements from roadmap.sh:
https://roadmap.sh/projects/server-stats
## How to run this project
1. Grant execute permissions to the script : 
	chmod +x name_file.sh
2. Run the script: 
 	./name_file.sh
